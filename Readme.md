# A-Maze-ing

## Description
Implementation of a maze generator in Python that takes a configuration file, generates a maze, possibly perfect (with a single path between entrance and exit), and writes it to a file using a hexadecimal wall representation. It also provide a visual representation of the maze and organize code so that the generation logic can be reused later
